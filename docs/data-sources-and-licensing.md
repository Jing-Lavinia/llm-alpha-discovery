# Empirical data and licensing

No market-data file is distributed in this repository.

The empirical panel was assembled from licensed market information for private research. The public release reports date coverage, tested universe size, and aggregate diagnostics without redistributing vendor files, security identifiers, observation-level extracts, or data-correction records.

Independent reconstruction requires appropriately licensed market data and separate implementation choices for instrument history, corporate actions, exchange calendars, suspensions, and liquidity measurement. Those choices can affect results and are not represented by the public evidence validator.

Third-party data rights remain with their respective owners. The repository license applies only to the materials actually distributed here.
